📐 How Court Calibration Works Planar Homography

Because camera angles differ from court to court, the system uses a 4-point homography calibration to calculate real-world meters from camera pixels:

To run on your custom video via CLI:
# 1. Calibrate corners for your video (click 4 corners)
python calibrate_court.py "path/to/my_video.mp4"

# 2. Run analysis with AI Coach
python squash_main.py "path/to/my_video.mp4" --config court_config.json
